# VisuAll

Projeto desenvolvido para o Challenge FIAP em parceria com a JOVI.

## Tecnologias utilizadas

- Next.js 16
- React
- JavaScript
- CSS puro
- localStorage

## Como instalar as dependências

```bash
cd webdev3
npm install
```

## Como executar o projeto

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Usuários e senhas para teste

O login não possui usuário pré-cadastrado. Para testar, clique em **Cadastre-se**, crie um usuário e uma senha e depois faça login com os mesmos dados. Os dados ficam armazenados no localStorage do navegador.

## Uso de Inteligência Artificial

A IA foi usada como apoio no aprendizado e na revisão do projeto. Ela ajudou a explicar conceitos básicos de React, como componentes, props e useState, e também auxiliou na lógica de login e cadastro com localStorage, na navegação do carrossel com operações matemáticas e na identificação de erros de configuração. Todas as alterações foram revisadas para manter o código simples e compreensível pela equipe.
